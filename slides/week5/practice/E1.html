E1: Revise a Prompt and Check Its Evidence

Learning Goal

Compare a vague prompt with a prompt you revise yourself, then check whether the response is supported by the supplied evidence.

E1 is plan only. This means the requested response may describe steps, inputs, rules, outputs, and checks. It must not run code, calculate numerical results, invent terminal output, or claim that anything was executed or verified.

Complete Input Data

Use exactly this dataset in both attempts. The same data are also available in motion.csv.

time_s,position_cm
0,1
1,3
2,
3,7
4,9
5,11

Complete Evidence Notes

Use all four notes in both attempts. The same notes are also available in motion_notes.md.

  • N1: time_s is time in s. position_cm is position in cm. Position includes a nonzero initial coordinate and must not be mislabeled as distance traveled from the origin.
  • N2: The position at time_s=2 is missing. The primary analysis excludes this row and records the reason. It does not fill the value with zero or interpolate it.
  • N3: Fit the remaining valid rows with an ordinary least-squares line that includes an intercept. Report velocity and initial position. Convert position from cm to m in the final plot.
  • N4: Temperature, measurement uncertainty, instrument details, and real experimental conditions were not provided. None of them can be inferred from these materials.

Choose One Participation Branch

Branch A: Two Chat Attempts

  1. Download or copy the blank prompt-check template and save your working copy as prompt-check.md.

  2. Start a fresh chat. Supply the complete CSV and N1–N4 above.

  3. Send this initial prompt exactly:

    Help me analyze the data. Propose an analysis plan only. Do not execute code or claim that any result has been calculated or verified.

  4. Paste the full initial prompt and full response into your template.

  5. Start another fresh chat. Use the same visible model and the same settings where possible. Supply the same complete CSV and N1–N4 again.

  6. Write your own revised prompt. Do not copy a worked prompt from another group. Your prompt must explicitly require the response to address every item in the revision checklist below, cite N1–N4, and remain plan only.

  7. Paste the full revised prompt and full response into your template.

  8. Exchange the completed template with a partner and perform the four evidence checks.

  9. Record every correction before submitting prompt-check.md.

Separate fresh chats reduce the chance that the second reply silently depends on the first conversation. Keeping the model and settings the same where possible makes the prompt revision the main planned difference. This comparison still does not prove that one prompting method is generally better.

Branch B: No Chat Account

  1. Download or copy the blank prompt-check template and select the offline branch.
  2. Open offline-response.md. It contains one teacher-written initial prompt and one intentionally unreviewed illustrative reply. It is not an actual model run.
  3. Copy that initial prompt and reply into Attempt 1 of the template.
  4. Check the reply against N1–N4. Record omissions or unsupported claims.
  5. Write your own revised prompt in Attempt 2. It must satisfy the revision checklist and remain plan only.
  6. Write Not generated — offline branch in the Attempt 2 response field. Do not invent a second model response.
  7. Ask a partner to review whether your revised prompt explicitly requires all four evidence items. Record corrections and submit prompt-check.md.

Revision Checklist

Your revised prompt must require the planned response to:

  1. distinguish time in s from position in cm, preserve the meaning of position, and state the required cm-to-m conversion for the final plot [N1];
  2. identify the missing position at t = 2 s, exclude that row, record why, and forbid zero filling or invented interpolation [N2];
  3. specify an ordinary least-squares line with an intercept and name velocity and initial position as outputs with units [N3];
  4. state that temperature, measurement uncertainty, instrument details, and real experimental conditions are not provided and must not be inferred [N4];
  5. cite the supporting note after each conclusion; and
  6. produce a plan only, with no code execution, calculated values, or verification claims.

Submission

Submit one completed prompt-check.md file based on the blank template. No script, plot, report, or run log is required for E1.
