Week 5 Student Practice: Prompts, Evidence, and Execution

This folder is a standalone practice package. All data and notes used by the exercises are included here.

Start Here

  1. Complete E1: Revise a Prompt and Check Its Evidence. E1 is required and does not require code execution.
  2. Save your work using the blank E1 prompt-check template.
  3. Complete E2: Execute and Verify an Analysis only if your class or group chooses the optional extension.

Required and Optional Work

  • Required: E1 produces one completed prompt-check.md file. E1 asks for an analysis plan only.
  • Optional: E2 produces your own script, plot, report, and run log. E2 requires access to a local Python environment if you do not use an Agent that can execute code.

If you have no chat account, you can still complete the offline branch of E1. If you also have no local Python environment, stop after E1. Do not claim that E2 was executed.

The optional Agent files are editable resources. Their presence in a folder does not prove that an Agent read or followed them. Check actual tool access, created files, terminal output, and your own inspection before making that claim.

These are synthetic classroom data. Do not upload unpublished research data, share credentials, or infer experimental conditions that are not in the supplied notes.
